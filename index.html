    About the DAA Algorithm

    This project demonstrates priority-based landing scheduling using a min-heap concept. The simulation processes the waiting flight with the lowest priority number first.

    Heap insertion: O(log n) Heap removal: O(log n) Sorting queue: O(n log n)
